# StudyFlow — Laravel Authentication & CRUD

Laravel 12 + Blade task manager for the Web Programming Lab Activity. Includes registration/login, password reset, authenticated task CRUD, SQLite migrations, ownership checks, and tests.

**Setup**: See the source README after the full project files are uploaded. PHP 8.2+, Composer, Node/npm, and PHP SQLite support are required. The full application has passed PHP syntax checks; integration tests require local setup and have not yet been executed.
